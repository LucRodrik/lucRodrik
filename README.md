## Sobre mim

Background em arte 3D, hoje construindo experiências mobile que conectam pessoas. Focado no ecossistema JavaScript para apps multiplataforma.

- 📱 Apps com **React Native** e **Expo Go**
- 🌐 APIs e back-end com **Node.js**
- 🔷 Tipagem forte com **TypeScript**
- 🏢 Membro do **Ujamaa Tech Studio** — Tecnologia que conecta, cria e transforma.
