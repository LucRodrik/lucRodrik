## Sobre

Fundador da **Tekoá Tecnologia** e criador do **Fatux** — plataforma de gestão financeira para autônomos e pequenos empresários via WhatsApp. Formado em Análise e Desenvolvimento de Sistemas (Estácio, 2026), atualmente em transição para desenvolvimento mobile com foco em React Native.

- 🧠 **Aprendendo agora** — JavaScript (sólido), TypeScript (próximo), React Native + Expo (em breve)
- 🏗️ **Construindo** — Fatux, meu primeiro produto SaaS
- 🎯 **Objetivo** — mobile developer remoto com produto próprio no mercado
